# 拾词 · Wordkeep

一个可直接加载的 Chrome Manifest V3 单词本插件：右键收藏英文单词，离线查中文释义，在多台电脑间通过 Chrome 账号同步。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 **`extension` 文件夹**，不要选项目根目录。
3. 在工具栏的扩展程序菜单中将「拾词」固定。
4. 打开任意有英文文本的网页，选中一个英文单词，右键选择「收藏到拾词」。
5. 点击拾词图标查看单词本。

无需安装 Node.js、运行服务器、填写密钥或执行构建。插件已经包含 399,213 个英文词条的离线中文释义，词库文件约 20.4 MB（十进制）。压缩安装包在 `artifacts/wordkeep-1.0.0.zip`，解压后同样选择其中的 `extension` 文件夹。

## 使用

- 支持英文单词及带英文撇号、连字符的单个词；短语、句子、数字暂不支持。
- `Apple` 与 `apple` 视为同一词；`run` 与 `running` 分别保存。
- 再次收藏已存在的词会显示 `=` 标记，保留第一次收藏时间与手动释义。
- 收藏成功显示 `✓`；仅本地保存显示 `•`；无效选择或保存失败显示 `!`，将鼠标停在图标上查看详情。
- 弹窗支持搜索英文或中文释义、修改释义、删除、导出 JSON。按 `/` 可聚焦搜索。
- 释义编辑留空后保存，会恢复内置词典释义；手动释义最多 1,000 个字符。
- 未收录词仍会被收藏，可手动补充释义。词典文件损坏时会明确显示错误。
- 删除会传播到其他电脑；再次主动收藏同一词会创建新的收藏记录。
- 「导出备份」包括所有当前单词、可见释义、手动释义、首次收藏时间，以及是否待提交。包括仅本地保存的单词。当前版本提供可读 JSON 导出，尚未提供一键导入。

## 在多台电脑同步

1. 在每台电脑手动安装同一份插件，登录同一个 Google 账号。
2. 在 Chrome「设置 → 你与 Google → 同步」中开启扩展程序相关同步；确保 Google 同步服务可访问。
3. 保持 `manifest.json` 的 `key` 不变。固定公钥让各电脑使用相同扩展 ID，移动插件文件夹不会改变 ID。
4. 两台电脑均打开插件，等待 Chrome 传输数据；可点击「重试提交」重新尝试把待处理数据交给 Chrome。

本版本固定扩展 ID：`pakljaaboegeogcampkipgnjanpdkinh`。

**「已提交 Chrome」不是其他电脑已收到的确认。** `chrome.storage.sync` 是本地可写的同步存储，Chrome 不提供逐条远端接收回执，也不通过此 API 暴露账号同步开关或强制立即上传能力。没有登录、同步关闭、网络不可达时，插件仍可本地使用。实际跨设备生效取决于 Chrome。

离线查询不需要网络。离线收藏先保存在本地，Chrome 在条件满足后继续同步。标准释义由各电脑内置词典提供，只将单词、时间、手动释义和必要的冲突信息交给 Chrome。

### 容量与冲突

- Chrome 同步总容量 102,400 字节，每项 8,192 字节、最多 512 项，并受写入频率限制。插件使用 128 个固定分片；可收藏数量取决于词长、手动释义和删除历史。
- 配额不足或同步写入失败时，本地数据保留，弹窗明确显示待提交数量；每分钟、浏览器启动、打开弹窗或点击重试时重新尝试。
- 手动释义较长时，恢复词典释义或删除不需要的词可释放一部分空间。删除保留精简的删除标记，避免离线设备把旧记录同步回来，因此**删除并不释放全部空间**。单个分片用满时也可能在总容量未满前显示待提交。
- 不同单词自动合并；同一词的释义按修改时间决定，时间相同时使用设备标识作确定性排序。设备时间误差可能影响先后顺序。
- 同一轮收藏中，删除优先于修改。主动重新收藏会开始新一轮，旧设备的旧操作不会覆盖这次新收藏。
- 本地存储也有 Chrome 配额；本地写入失败会报错，绝不会误报收藏成功。卸载插件会删除本机数据，卸载前请导出备份。

## 隐私与权限

只申请 `contextMenus`（右键菜单）、`storage`（存储）、`alarms`（重试）。不申请站点权限，不读取整页内容，不收集来源网址，不调用在线翻译服务，不包含遥测。用户选中的词、手动释义和收藏元数据会按 Chrome 的同步设置交给 Google。

## 开发与验证

使用 Node.js 22+，核心运行及测试均无需 npm 依赖：

```sh
npm test
npm run check
npm run package
```

打包命令需要系统 `zip`。插件运行无需这些开发工具。重新生成离线词库：`npm run dictionary`；首次构建会下载固定版本的 ECDICT，随后复用 `.cache`。源 CSV 的 SHA-256 必须与固定版本相符。

浏览器冒烟测试使用可选的 `puppeteer-core` 和 Chrome for Testing，设置 `WORDKEEP_BROWSER` 为浏览器可执行文件，`WORDKEEP_PUPPETEER` 为已有 Puppeteer ESM 入口（不设置时使用本地安装的 `puppeteer-core`），运行 `node tests/browser-smoke.mjs`。测试只使用 `artifacts` 下的独立测试档案，不接触日常浏览器账号。截图和报告写入 `artifacts`。

浏览器测试会在临时副本里捕获并调用真实右键菜单回调，验证插件、存储与界面；原生右键菜单点击及真实 Google 账号传输需按 [验收步骤](docs/ACCEPTANCE.md) 在两台电脑验证。

## 文件结构

- `extension/`：可以直接加载的完整插件。
- `extension/core/`：词条合并、本地保存、同步配额处理和离线查词。
- `extension/dictionary/`：分片词库、来源元数据和原始许可。
- `scripts/`：词库与图标生成、静态检查、打包。
- `tests/`：冲突、离线、容量、持久化、真实词库和浏览器测试。
- `docs/`：设计与手工验收说明。

词库来源：[ECDICT](https://github.com/skywind3000/ECDICT)，固定提交 `bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`。保留英文单词与中文释义，过滤短语，大小写合并；原始许可保存在 `extension/dictionary/ECDICT-LICENSE.txt`。

相关官方文档：[Chrome 存储与配额](https://developer.chrome.com/docs/extensions/reference/api/storage)、[固定扩展 ID](https://developer.chrome.com/docs/extensions/reference/manifest/key)。
