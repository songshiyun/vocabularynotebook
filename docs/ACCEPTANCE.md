# 两台电脑验收

## 安装和右键收藏

1. 两台电脑加载相同 `extension` 文件夹，检查扩展 ID 一致。
2. 登录同一 Chrome 账号并开启扩展程序数据同步。
3. 在普通网页选中 `resilient`，右键选择「收藏到拾词」。图标应显示 `✓`，打开弹窗可看到中文释义和收藏时间。
4. 再次收藏 `RESILIENT`，图标显示 `=`，条目数量与原时间不变。
5. 选中一句英文或中文，执行右键操作，图标显示 `!`，提示只支持单个英文单词，不生成新记录。

## 离线和持久化

1. 断网后在已经打开的网页收藏 `algorithm`，弹窗仍可显示包含「算法」的中文释义。
2. 编辑释义，关闭并重开弹窗，确认内容保留。
3. 关闭并重开 Chrome，确认内容保留。
4. 联网后等待 Chrome 同步，在另一台电脑确认词条和手动释义出现。

## 同步冲突

1. 两端确认已拥有同一词条。
2. 两台电脑断网，分别新增不同单词；联网后两个新增单词均应保留。
3. 两端断网，依次修改同一个词的释义；联网后两端最终使用较新修改。请先确保两台电脑系统时间正确。
4. 两端断网，一端删除某词，另一端编辑同词释义；联网后两端最终均删除该词。
5. 删除已传播后，主动再次收藏同词；新记录应能同步，首次收藏时间更新。

## 空间不足和导出

1. 在专用测试档案中积累足够多单词或较长手动释义，直到同步配额不足。
2. 继续收藏新词，确认仍可在本机查看，并显示「仅本地 · 待提交」。
3. 导出 JSON，确认其中包括待提交词、释义和时间。
4. 精简已有手动释义，点击重试；空间足够时，待提交记录应逐步提交到 Chrome。
5. 总空间不足、单分片达到 8 KB，以及保留删除标记都可能影响可用容量；不要期待删除后容量归零。

## 注意

「已提交 Chrome」只表示本机 Chrome 接受了数据，并不是远端回执。关闭账号同步时，插件无法代替 Chrome 将数据发到另一台电脑；点击「重试提交」也不能绕过账号或网络问题。

真实跨电脑 Google 同步必须由两台已登录的设备验收，自动化测试没有访问个人 Google 账号。
